# 起卦算法口径规范（qigua-najia-v1）

> 本文件是**代码口径的唯一说明**。任何数值都不得由模型心算——所有取数、余数、卦名、动爻、
> 变卦都由 `scripts/meihua.mjs` / `scripts/external.mjs` 计算，模型只读结果。
>
> 版本：`qigua-najia-v1`（算法版本写死进每一次输出；口径一旦变更必须升版本号，不得静默切换）。

---

## 1. 通用约定

### 1.1 爻画编码

- 六爻二进制一律 **初爻→上爻（自下而上）**，`1` 阳 `0` 阴，长度恒为 6。
- 前三位 = 下卦（内卦），后三位 = 上卦（外卦）。**不得因图形展示方向反转。**
- 爻位编号：`1` 初爻 … `6` 上爻；数组索引 `0`–`5`。索引与爻位的换算只在代码里做一次。

### 1.2 先天八卦数（《梅花易数·周易卦数》）

| 数 | 卦 | 二进制（自下而上） | 五行 |
|---:|---|---|---|
| 1 | 乾 | 111 | 金 |
| 2 | 兑 | 110 | 金 |
| 3 | 离 | 101 | 火 |
| 4 | 震 | 100 | 木 |
| 5 | 巽 | 011 | 木 |
| 6 | 坎 | 010 | 水 |
| 7 | 艮 | 001 | 土 |
| 8 | 坤 | 000 | 土 |

（五行仅用于展示，纳甲装卦的五行由引擎按纳甲规则给出，不得用此表替代。）

### 1.3 余数函数（《卦以八除》《爻以六除》）

```text
remainderToEight(n):  r = n % 8;  返回 8 if r == 0 else r      # 整除取坤八
remainderToSix(n):    r = n % 6;  返回 6 if r == 0 else r      # 整除取第六爻（上爻）
```

- 输入域限定为**非负整数/正整数**，避免各语言负数取模差异。
- 两数法内部全程 `BigInt`，**不得用浮点数**（大数会丢精度导致卦变）。
- 实现：`scripts/meihua.mjs::remainderToEight / remainderToSix`。

### 1.4 爻值编码（向纳甲引擎表达「阴阳 + 动静」）

| 爻态 | 爻值 |
|---|---:|
| 静阳（少阳） | 7 |
| 静阴（少阴） | 8 |
| 动阳（老阳） | 9 |
| 动阴（老阴） | 6 |

投掷值 → 二进制：`7|9 → 1`，`6|8 → 0`；动爻 = `6|9` 的爻位；变爻 = 动爻取反。

> 梅花两法的 6/7/8/9 是**由「恰好一条动爻」规则映射出的内部编码**，不是摇出来的铜钱数值，
> 报告中不得表述为「摇得老阳/老阴」。

## 2. 方式 A：时间起卦（年月日时）

### 2.1 公式（《梅花易数·年月日时起例》）

```text
年支数 N = 农历年地支序数（子 1、丑 2、寅 3、卯 4、辰 5、巳 6、午 7、未 8、申 9、酉 10、戌 11、亥 12）
农历月数 M = 正月 1 … 十二月 12（闰月取绝对值，并记录 is_leap_month）
农历日数 D = 初一 1 … 三十 30
时支数 H = 时辰地支序数（子 1 … 亥 12）

S1 = N + M + D
S2 = S1 + H

上卦数 = remainderToEight(S1)      # S1 % 8，0 → 8
下卦数 = remainderToEight(S2)      # S2 % 8，0 → 8
动爻位 = remainderToSix(S2)        # S2 % 6，0 → 6
```

- 本卦 = 下卦（内，初二三爻）+ 上卦（外，四五六爻）。
- 梅花时间法**恰好一条动爻**；变卦 = 只翻转该爻，其余五爻不动。
- 变卦卦名必须由六十四卦表反查（`SIXTY_FOUR_HEXAGRAMS`），不得手写。

### 2.2 历法口径（硬性，不许换流派）

| 项 | 采用 | 禁止 |
|---|---|---|
| 年 | **农历年支**（正月初一换年）＝`lunar.getYearZhi()` | ❌ `getYearZhiExact()`（立春换年）、八字年柱 |
| 月 | 农历月（闰月取绝对值） | ❌ 节气月、月建、八字月柱 |
| 日 | 农历日 | ❌ 公历日、节气交接修正 |
| 时 | **时支**（两小时一支） | ❌ 时干、真太阳时修正 |
| 换日 | 民用日 00:00 换日：23:00–23:59 属子时，但农历日仍按**当日民用日期** | ❌ 23:00 换日（子初换日） |

- 时辰区间：子 23:00–00:59、丑 01:00–02:59、寅 03:00–04:59 … 亥 21:00–22:59。
- `lunar.getYearZhiExact()` 只在输出里作为 `year_zhi_exact_reference_only` **备查**，不参与取数
  （用于向用户解释「为什么这里不是立春换年」）。
- 闰月、23 点子时、农历月末、时区/夏令时边界：输出必须记录解析前后口径（`resolved_from`、
  `is_leap_month`、`dst_ambiguous`、`wall_clock`）。

### 2.3 时间字段（两把时间，不许混用）

| 字段 | 用途 | 谁用 |
|---|---|---|
| `meihua_reference_time` | 梅花取数（年月日时） | 仅时间法 |
| `najia_cast_at` | 纳甲月建/日辰/六神/旬空 | 三种入口都必须有 |

- 当前时间起卦：两者同一时刻（输出 `same_moment: true`）。
- 用户指定「事件时间/原始发布时间」取数时：`meihua_reference_time` 用事件时间，
  `najia_cast_at` 仍用**实际占问时间**，输出 `same_moment: false` 并明示「双时间基准」，
  不得隐瞒。
- 时区必须以 IANA 名称显式给出（`Asia/Shanghai`），**不得用设备时区兜底**；
  无时区 → `INVALID_INPUT`。

### 2.4 输入校验

- 时间必须含日期 + 本地时刻，可选 `±HH:mm`；格式 `YYYY-MM-DDTHH:mm(:ss)` 或 `YYYY-MM-DD HH:mm`。
- 若同时给 UTC 偏移与 IANA 时区，二者必须自洽，否则 `INVALID_INPUT`。
- 落在夏令时跳变空档的时刻 → `INVALID_INPUT`（不存在该墙上时间）。
- 落在夏令时回拨的重复时刻 → 采用后一个瞬时，输出 `dst_ambiguous: true`。

## 3. 方式 B：两数报数

### 3.1 公式

```text
A = 第一个正整数     B = 第二个正整数

上卦数 = remainderToEight(A)      # A % 8，0 → 8
下卦数 = remainderToEight(B)      # B % 8，0 → 8
动爻位 = remainderToSix(A + B)    # (A+B) % 6，0 → 6
```

- 只此一条口径：**不加时辰、不换第三个数、不随机、不因结果不理想而重报**。
- 两数法**恰好一条动爻**；变卦只翻该爻。
- 两数法仍需记录 `najia_cast_at`（用户提交占问的实际时间）供纳甲引擎使用，
  该时间**不参与**梅花卦数计算。

### 3.2 输入校验

- 只接受正整数。负数、0、小数、`"3.5"`、空值、`null`、非数字字符串、对象 → `INVALID_INPUT`。
- 内部用 `BigInt`：`1e20` 级别的数也能精确取模，不产生浮点误差。
- 数字字符串 `"5"` 等价于 `5`（便于 CLI 传参）。

### 3.3 文献边界（重要）

「第一数定上卦、第二数定下卦、两数之和定动爻」是**现代通行的标准化交互口径**，
《梅花易数》卷一只有「卦以八除、爻以六除」的数理基础与《物数占例》一类的取数示例。
**不得宣称两数法是该卷原文逐字规定**。详见 `references/source-notes.md`。

## 4. 方式 C：外部卦象输入（四种模式）

此模式**不是梅花起卦**：不取数、不算年月日时、不受「恰好一条动爻」约束。
允许 **0–6 条动爻**；多动爻**全部保留**；静卦就是静卦（`changed = null`）。

### 4.1 模式 C-1：六爻爻值 `SIX_LINE_VALUES`

```text
values = [6|7|8|9] × 6            # 初爻→上爻；第一次摇卦=初爻，第六次=上爻
本卦爻 = (v in {7,9}) ? 阳 : 阴
动爻   = { i | v_i in {6,9} }
变卦爻 = 动爻取反，静爻不动
静卦   = 六个爻值全为 7/8 → moving_lines = []、无变卦
```

### 4.2 模式 C-2：本卦 + 变卦 `ORIGINAL_PLUS_CHANGED`

```text
逐位比较两卦六爻（初爻→上爻）：
  阳→阴 = 9 老阳动
  阴→阳 = 6 老阴动
  阳→阳 = 7 少阳静
  阴→阴 = 8 少阴静
moving_lines = 全部阴阳不同的爻位（精确等于两卦差异集）
两卦相同 → 识别为静卦（moving_lines=[], changed=null）；若同时声明有动爻 → 冲突
```

> 只凭本卦**无法**反推动爻。必须有变卦、或动爻位置、或明确的静卦声明。

### 4.3 模式 C-3：本卦 + 动爻位置 `ORIGINAL_PLUS_MOVING_LINES`

```text
lines = 本卦六爻
选中动爻编码：阳爻→9、阴爻→6；未选中：阳→7、阴→8
变卦 = 翻转全部选中爻位（代码生成，用户不填卦名）
moving_lines 可为空，但为空时必须显式 is_static=true，否则 MISSING_CHANGE_INFORMATION
```

### 4.4 模式 C-4：明确静卦 `ORIGINAL_STATIC`

```text
lines = 本卦六爻（阳 7、阴 8）
moving_lines = []
changed_hexagram_id = null
is_static = true
```

> 静卦是**有效完整输入**，不是数据错误。不得为了兼容显示把本卦复制成变卦
> 制造「本卦=变卦」的假变卦，也不得把静卦伪造成一条动爻。

### 4.5 冲突检测（全部机器判定）

| 检查 | 失败错误码 |
|---|---|
| 卦名无法唯一映射到六十四卦（须全名，如「泽火革」） | `INVALID_INPUT` |
| 爻值不在 `{6,7,8,9}`、数组长度 ≠ 6 | `INVALID_INPUT` |
| 动爻位置不在 1–6、重复 | `INVALID_INPUT` |
| 爻值推出的本卦 ≠ 用户给出的本卦 | `CONFLICTING_HEXAGRAM_INPUT` |
| 爻值推出的变卦 ≠ 用户给出的变卦 | `CONFLICTING_HEXAGRAM_INPUT` |
| 本卦↔变卦差异集 ≠ 用户声明的动爻集合 | `CONFLICTING_HEXAGRAM_INPUT` |
| 本卦 = 变卦 却声明有动爻 | `CONFLICTING_HEXAGRAM_INPUT` |
| 声明静卦却有动爻 / 给了不同变卦 | `CONFLICTING_HEXAGRAM_INPUT` |
| 变卦 ≠ 翻转全部动爻的结果 | `INTERNAL_CONSISTENCY_ERROR` |
| 只给本卦，无变卦/动爻/静卦声明 | `MISSING_CHANGE_INFORMATION` |
| `moving_lines: []` 但无静卦声明 | `MISSING_CHANGE_INFORMATION` |
| 外部输入携带 `meihua_reference_time` | `INVALID_INPUT` |
| 起卦时间为空 / 时区为空 | `INVALID_INPUT` |

模式可显式给出 `input_mode`；未给出时按字段存在性**确定性推断**
（爻值 → 本卦+变卦 → 本卦+动爻 → 本卦+静卦），推断不出即失败关闭。

## 5. 一致性闸门（调用引擎前后）

1. 梅花两法：`moving_lines.length === 1`；外部：`0 ≤ length ≤ 6`，且全部保留。
2. 变卦 = 翻转全部动爻；静卦 `changed === null`。
3. 引擎返回的 `base.binary` / `base.name` / `movingLines` / `changed.binary` / `input.coins`
   必须与本 Skill 的计算结果逐项相等，否则 `INTERNAL_CONSISTENCY_ERROR` 并停止断卦。
4. 静卦时引擎必须返回 `changed === null`、`changedLines === []`。

任何一项失败：**立即停止**，输出错误码；不得让模型「修一下数据再算」。

---

## 6. 错误码总表

| 错误码 | 含义 | 处理 |
|---|---|---|
| `INVALID_INPUT` | 格式/范围/名称不合法、缺时间或缺时区 | 停下来问用户补 |
| `MISSING_CHANGE_INFORMATION` | 只有本卦，缺动爻/变卦/静卦声明 | 停下来问：动爻？变卦？还是静卦？ |
| `CONFLICTING_HEXAGRAM_INPUT` | 爻值/本卦/变卦/动爻互相矛盾 | 停下来，指出矛盾点，不猜哪套对 |
| `INTERNAL_CONSISTENCY_ERROR` | 引擎输出与计算不一致（数据或代码被改坏） | 停下来报告，不产出断卦 |

CLI 表现：错误 JSON 打到 stderr，退出码 `2`，`fail_closed: true`。

## 7. 禁止事项（违反即返工）

1. 禁止模型心算取数、把数字映射成卦、按卦名反推爻画、猜动爻、手写变卦。
2. 禁止把梅花体用/生克混入纳甲用神体系；禁止把梅花起卦包装成铜钱摇卦。
3. 禁止把外部卦象输入标成梅花起卦，或伪造 `meihua_reference_time`。
4. 禁止把多动爻压成一条，禁止把静卦伪造成「本卦=变卦」的假变卦。
5. 禁止用节气月/立春换年替换梅花取数口径。
6. 禁止在本 Skill 里重写纳甲/世应/六亲/六神/旬空算法（只用 `scripts/engine/` 的复制引擎）。
