# 文献依据与口径边界（source notes）

> 本文件回答三个问题：梅花两法的**文献依据是什么**、**哪些是现代口径**、
> 以及**观梅占样例**为什么能当黄金测试。运行时不读本文件的断语，只读 `scripts/` 的输出。

---

## 1. 《梅花易数》卷一依据

传本参考：维基文库《梅花易数》卷一 <https://zh.wikisource.org/zh-hans/梅花易数/卷一>。

| 篇目 | 要点 | 本 Skill 对应实现 |
|---|---|---|
| 《周易卦数》 | 乾一、兑二、离三、震四、巽五、坎六、艮七、坤八 | `XIANTIAN_NUMBER_TO_TRIGRAM` |
| 《卦以八除》 | 以八除取卦，整除取坤八 | `remainderToEight`（余 0 → 8） |
| 《爻以六除》 | 重卦总数除六取动爻，整除取第六爻 | `remainderToSix`（余 0 → 6，即上爻） |
| 《年月日时起例》 | 年月日取上卦，年月日加时取下卦，以总数取动爻 | `castMeihuaTime`：S1=年+月+日，S2=S1+时 |
| 《物数占例》 | 以可数之物取上卦，以时数配下卦，物数与时数总数取爻 | 与两数法共享「除八取卦、除六取爻」的数理 |
| 《为人占》 | 起卦来源可为年月日时、声音、人物、物象、服色、外物、书写来意等 | 说明「起卦来源多样」；本 Skill 只实现时间法与两数法两种确定性入口 |

关键点：

1. **「卦以八除、爻以六除」是硬规则**，整除时分别取坤（8）与第六爻（6），不是取 0。
2. 时间法的「年月日」用的是**农历**年月日与**地支序数**（子 1 … 亥 12），
   不是公历、不是节气月、不是八字月柱。
3. 卷一还有大量「声音占、字占、颜色占」等取数法，本 Skill **不实现**：
   没有确定性输入契约的方式一律不猜（要求用户改用时间法/两数法/外部卦象）。

## 2. 两数法的现代边界（必须如实披露）

**《梅花易数》卷一并没有逐字规定**「第一数定上卦、第二数定下卦、两数之和定动爻」这套
两数交互流程。卷一只给出取数与除八除六的**数理基础**（《卦以八除》《爻以六除》《物数占例》）。

因此本 Skill 的定位是：

- **文献基础**：取数 → 除八得上下卦 → 除六得动爻，这套数理与卷一一致。
- **现代标准化**：`A→上卦、B→下卦、动爻=(A+B)%6` 是为产品交互固定的便捷口径，
  **属于现代标准化实现，不是原文逐字记载**。
- **锁定不切换**：一次成卦到底用哪套口径，必须在算法版本里写死。
  不得「有时加当前时辰、有时不加」，不得「换第三个数取动爻」，不得为凑吉卦重报数字。
- 若要支持别的报数流派（例如加时辰、或三数法），必须作为**新的显式算法版本**
  （`qigua-najia-v2` 等），不得静默替换。

同理，时间法的「闰月取绝对值」「民用日 00:00 换日」也是**软件统一口径**，
不是所有传承的唯一说法；输出中必须记录 `is_leap_month` / 换日说明，便于复核。

## 3. 观梅占黄金样例（测试 A）

传统记载（《梅花易数》卷一「观梅占」）：辰年、十二月、十七日、申时。

取数与卦象（本 Skill 代码复算，与原文一致）：

```text
年支 辰 = 5，农历月 = 12，农历日 = 17，时支 申 = 9
S1 = 5 + 12 + 17 = 34
S2 = 34 + 9 = 43
上卦 = 34 % 8 = 2 → 兑
下卦 = 43 % 8 = 3 → 离
动爻 = 43 % 6 = 1 → 初爻
本卦 = 上兑下离 = 泽火革（二进制 101110）
初爻动 → 变卦 泽山咸（二进制 001110）
```

可复算的对应公历时刻（用于测试）：`2025-01-16 15:30 Asia/Shanghai`
的农历正是「甲辰年 腊月十七 申时」。

古籍原断走的是**梅花体用**一路（动爻所在的下卦离火为用、上卦兑金为体，用克体；
互卦取二三四爻为巽、三四五爻为乾，成天风姤），据此论「有女子折花、园丁逐之、坠地伤股」之类。
**本 Skill 不输出这套梅花断语**：

- 体用/生克/互卦属于纯梅花分析，需另开独立流程；
- 本 Skill 的断卦体系是**纳甲六爻**（取用神、世应、月建日辰、旬空、动变），
  两者不得混用，也不得把「体卦/用卦」说成「世爻/应爻」。

该样例在本仓库里的用途只有一个：**验证取数、上下卦、动爻、变卦四个环节的代码正确性**
（`tests/cast.test.mjs` 测试组 A）。

## 4. 外部卦象输入的依据与边界

- 依据：真实手摇（三钱法）／蓍草（大衍筮法）／第三方排盘软件都能给出 6/7/8/9 或本卦变卦。
  《卜筮正宗》《增删卜易》一路的纳甲六爻，本就以**实际摇得的动静**为准，
  可以静卦、可以一爻动、也可以多爻动，**不存在「一卦只能一条动爻」的限制**。
- 边界：
  - 「恰好一条动爻」是**梅花**规则的产物，不得倒灌进外部输入；
  - 静卦是完整输入，不是缺数据；不得用「本卦=变卦」伪装；
  - 外部输入不取梅花数，不标记为梅花起卦，也不伪造 `meihua_reference_time`；
  - 若用户只给卦盘截图或模糊描述，必须要求其确认爻值/本卦/动爻/变卦，
    **不得由模型看图猜爻画**（猜出来的盘面等于伪造事实）。

---

## 5. 本 Skill 明确不做的事

1. 不做纯梅花体用断卦、不做互卦/错综卦推演（要就另开流程）。
2. 不实现声音占、字占、颜色占、方位占等无确定性输入的取数法。
3. 不重算纳甲、世应、六亲、六神、旬空、月建日辰（一律用 `scripts/engine/` 的复制引擎）。
4. 不因用户说「这卦不好，重摇/重报」而重算同一件事（可记录新的一卦，但两卦独立，不得择优）。
5. 不修改原断卦规范 `references/duangua-prompt.md` 的任何一个字。
